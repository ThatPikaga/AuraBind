# Contributing to AuraBind

Thank you for your interest in improving AuraBind! This plugin is open-source under the MIT license, and community contributions are highly welcome. 

To keep the codebase stable and maintain a great experience for Omarchy users, please follow these guidelines.

## How to Contribute

### 1. Reporting Bugs & Feature Requests
* Search the existing issues before opening a new one to avoid duplicates.
* Provide clear steps to reproduce bugs, including your Hyprland version and relevant logs if applicable.

### 2. Submitting Pull Requests (PRs)
* **Fork the repo** and create your feature branch from `master`.
* **Keep PRs focused.** Avoid mixing unrelated bug fixes and feature additions into a single PR.
* **Test your changes locally** on an active Omarchy environment before submitting.
* Ensure your code does not break existing write-through functions to `~/.config/hypr/bindings.lua`.

## Review and Merge Process

* **You maintain control:** Every pull request requires manual review and approval by the repository owner (`ThatPikaga`) before it is merged.
* **Feedback:** If modifications are needed, feedback will be provided directly within the PR comments.
* **Marketplace Updates:** Once a PR is merged into the `master` branch, the live Omarchy Marketplace registry will reflect the update according to its standard sync cycle.

Thank you for helping make AuraBind a seamless keybinding overlay for the Omarchy community!
